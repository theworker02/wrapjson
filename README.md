# wrapjson

Wrap validation gates for json inputs before they hit prod.

**Site:** https://theworker02.github.io/wrapjson/

## Install / run

```bash
git clone https://github.com/theworker02/wrapjson.git
cd wrapjson
node src/cli.js
node --test
```
